# First End-to-End Run: ERC4626 Inflation Fixture

Date: 2026-06-15

Fixture: `examples/erc4626_inflation_fixture/`

Goal: validate that ZeroPath can ingest a small vulnerable vault, infer the
right protocol shape, generate a share-inflation hypothesis, **generate and run
an executable Foundry proof**, measure the exploit impact, and only then let the
judge mark the candidate report-ready and export a final report.

This run supersedes the earlier skeleton-only run: `prove` now emits a runnable
Foundry test (not comments), `forge test` passes, and the measured attacker
profit flows through to a report-ready Code4rena report.

The hand-written fixture test demonstrates the donation-sensitive inflation

## ZeroPath Commands Run

From `examples/erc4626_inflation_fixture/`, using the repo virtualenv binary
(`../../.venv/bin/zeropath`):

```bash
zeropath init
zeropath ingest --repo .
zeropath understand
zeropath hunt --mode critical --limit 5
zeropath candidates list
zeropath prove ZP-001 --backend foundry
zeropath judge ZP-001
zeropath report ZP-001 --format code4rena
```

## Anti-Condition (Protected Vault) Behavior

`examples/erc4626_protected_fixture/` is the inverse vault: it tracks assets
internally and uses a decimals offset. `zeropath.core.inflation_guards` flags
`virtual_shares` and `internal_accounting`, so absent a passing PoC the judge
**blocks** that candidate with a clearly-marked heuristic anti-condition
objection instead of reporting it. A passing PoC with measured profit overrides
the heuristic (evidence beats a source-pattern guess).

## Remaining Limitations

- Concrete proof generation supports the ERC4626 inflation benchmark fixture and
  simple vault-like contracts only. The template assumes a single-asset vault
  constructor (`new Vault(token)`) and a no-arg mock asset constructor.
- Anti-condition detection is heuristic (regex over source), not a full ERC4626
  semantic analysis; hits are labelled `heuristic` and a passing PoC overrides
  them.
- The protocol summary still lists helper/test contracts (`MockERC20`, `Actor`,
  `VulnerableVaultTest`) alongside the affected `VulnerableVault`.
- No generalized PoC synthesis for other bug classes yet; non-inflation
  candidates still fall back to the comment skeleton.
